## 1. 项目简介

- **产品**：中国象棋微信小程序，支持三种模式：标准对局 `standard`、揭棋 `flip`、揭棋全随机 `random`
- **玩法**：双人在线对战（WS 实时同步）、房间制（建房/加入房间号/分享链接）、悔棋、认输、再来一局
- **特色**：暗棋（未翻开按位置行为走，翻开按真身）、全随机发牌（暗子归属跟所在半场）、上帝模式（昵称"炫"透视）、局内表情、背景音乐、将军变速
- **平台**：微信小程序为主，H5 可跑（uni-app 跨端）

## 2. 技术栈与环境

| 层 | 技术 |
|---|---|
| 前端 | uni-app（Vue 3）+ Vite，微信小程序构建产物 `dist/build/mp-weixin` |
| 游戏引擎 | 纯 JS 自研，`src/game/xiangqi.js`（与 UI 解耦，后端同引擎） |
| 后端 | Node.js + **Express**，REST `/api/*` + WebSocket `/ws`（token 鉴权） |
| 线上后端 | `https://gcwtnunyhfap.sealosbja.site` ，WS：`wss://gcwtnunyhfap.sealosbja.site/ws` |
| 联调 | H5 开发用 Vite proxy；小程序需在后台配 request / socket / downloadFile 合法域名 |

**常用命令**（PowerShell）：

```powershell
npm install
npm run dev:mp-weixin      # 开发模式监听编译 → dist/dev/mp-weixin
npm run build:mp-weixin    # 生产构建 → dist/build/mp-weixin
npm run dev:h5             # H5 调试
```

> ⚠️ **改完代码必须重新编译**，微信开发者工具/真机跑的是 `dist` 产物；真机预览要先删除最近使用的小程序再扫码，否则容易跑旧包。

## 8. 关键约定速查（踩坑点）

- **统一响应** `{code, msg, data}`；`code===0` 成功，非 0 时 `msg` 可直接 toast。错误码见《后端接口文档》§7。
- **棋子表示**：`t` 恒大写（K/A/B/N/R/C/P/?），颜色**只看 `color` 字段**（red/black）；前端渲染时按 color 归一大小写。暗子 `hidden:true` 时 `t:"?"`。
- **终局 reason 枚举**严格只用：`绝杀` / `困毙` / `认输` / `超时`（其他值前端会立即弹窗不延时）。
- **WS 消息**：`room_update / game_start / move_applied / game_over / undo_request / undo_result / opponent_offline / emoji / phrase`。
- **WS 连接**：单例幂等，跨页面复用；`socketTask.send` 发送；含 ping/pong；页面 onUnload 只取消订阅不关连接。
- **opponent_offline**：后端 10s 宽限 + 前端 3s 去抖，且后续 room_update 显示对手仍在则忽略。
- **全随机有效阵营**：暗子归属/吃子权限/送将保护按"位置方"（row>=5 红）；翻开后归真身颜色方；random 模式战利品全公开（flip 模式对方暗子显示"?"）。
- **落子判定分界**：掩码盘（暗子 Q/q、颜色=位置方）用于落子前合法性校验防泄密；真盘用于落子后 check/将死/困毙/翻棋送将判定。
- **上帝模式**：仅昵称严格等于 `炫`（区分大小写、trim）；god 视角真身只下发给 god 客户端；god-swap 需 moveCount 版本校验防竞态。
- **登录**：不本地存用户名，重启小程序需重新登录；头像非 https URL（wxfile/blob 等）经 localToDataUrl 压缩 base64 后再提交。
- **Vue 组件**：多个 methods 块必须合并；头像 error 用具名方法 `onAvatarError`（小程序兼容性）。
